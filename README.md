# freudenthal-duality-arithmetic

Code and computation logs for the series *Arithmetic of Freudenthal Duality*.

| Part | Topic | Folder |
|---|---|---|
| I | STU black holes and Bhargava cubes: integrality of the Freudenthal dual, U-duality criteria, exact counts, Dirichlet series and densities, the five-dimensional Jordan dual | [`part1`](part1) |

Each part has its own `README.md`, a `run_all.sh` that reproduces every computation, the source in `src/`, and the logs in `logs/`.
